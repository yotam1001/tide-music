# Tide logo

`tide-logo.svg` is the master. Every other icon file is rendered from it:
`tide-logo-source.png` (2048 px, also the macOS iconset source because it is the
largest PNG in this folder), `tide-icon.png` (256 px), `tide.ico` (16–256 px,
each size rendered directly from the vector), `video/assets/brand/` and the
browser-companion icons.

Concept (2026-11-24): a cream disc (a record, and the moon that drives the tide)
split by one breaking wave whose curl wraps the rose centre hole. The concept
image came from Gemini image generation and was traced to a vector, keeping its
shapes and colours: wine `#83203C`, cream `#F7F0D6`, rose `#BC3E64`.

Concept prompt: "Your single best idea for a more distinctive, ownable Tide mark,
e.g. a wave inside a circle/disc like a vinyl, or a tide-line/moon." Flat, bold,
geometric, no text, wine rounded-square tile filling about 85% of the canvas.
