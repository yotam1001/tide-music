# Tide brand files

The master logo is [`ui/assets/tide-logo.svg`](../../ui/assets/tide-logo.svg).
Everything here is rendered from it.

| File | Use |
|---|---|
| `tide-logo-1024.png`, `tide-logo-4096.png` | App-icon style: rounded tile on transparent. Press kits, docs, store listings. |
| `tide-avatar.svg`, `tide-avatar-1024.png`, `tide-avatar-4096.png` | Square, edge-to-edge tile with no transparency. Profile pictures (YouTube, TikTok, Instagram, Discord). Safe for circle crops: the disc stays whole. |
| `tide-logo-nobg.svg` / `-2048.png` | The disc alone with the wave cut out (transparent). For dark backgrounds. |
| `tide-logo-reversed.svg` / `-2048.png` | Cream tile, wine disc, cream wave. For dark surfaces where the wine tile would sink. |
| `tide-logo-reversed-nobg.svg` / `-2048.png` | Wine disc with the wave cut out (transparent). For light backgrounds. |

Colours: wine `#83203C`, cream `#F7F0D6`, rose `#BC3E64`.
