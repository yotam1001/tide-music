# Implementation contracts

The root owns Cargo.toml, crates/core, crates/app, documentation and packaging. UI worker owns ui/ only. Playback worker owns crates/playback/ and may add its crate manifest. Shared types are in tide-core.

UI contract: export AppWindow and TrackRow { title: string, artist: string, album: string, duration: string }. AppWindow properties: rows [TrackRow], current-index int, track-title string, track-artist string, track-album string, position float, duration float, paused bool, volume float (0..100), status-text string, source-input string, light-mode bool, collapsed bool, repeat-enabled bool. Callbacks: add-source(string), select-track(int), toggle-pause(), next-track(), previous-track(), seek(float seconds), change-volume(float), toggle-repeat(), switch-mode(), collapse-player(), open-file(), clear-queue(). Callbacks may be extended only with parent notice. Use one AppWindow switching conditional views; lazy mode components must not instantiate full library when light mode is active. No UI Rust wiring from worker.

Playback contract: pub fn start() -> Result<PlaybackHandle,String>; PlaybackHandle has send(PlaybackCommand)->Result<(),String> and snapshot()->PlaybackSnapshot. Core types imported from tide-core. Handle Drop requests shutdown and guarantees no orphan owned process. Backend can be native mpv with JSON IPC, audio only, no video decode, no shell command interpolation. Find mpv in app-adjacent tools directory or PATH, yt-dlp similarly. Clear missing-dependency errors. No automatic credential scanning; no cookies/secrets. Network playback is unavailable until the runtime exists. Restrict input to local file or validated http/https URL, pass as one argument or JSON field. Loading must cancel old track; metadata and errors must belong to active generation. Use bounded channels and efficient event-driven worker. Worker must document unresolved behavior.
