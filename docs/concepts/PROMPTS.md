## Concept 01: dark

Use case: ui-mockup
Asset type: high fidelity desktop application design concept, not a functioning app
Primary request: Design a custom lightweight native music player for Windows intended for listening to YouTube Music while gaming. Show the main desktop window and a separate compact mini-player beneath it on a neutral dark presentation background. This is a usable, restrained music app, not a gaming dashboard.
Style: crisp native desktop UI, excellent spacing, readable modern sans-serif typography, charcoal surfaces, soft borders, one muted mint accent, minimal shadows, no glass blur or neon glow.
Composition: landscape presentation, large main window with thin native-style title bar and left navigation, track-list center, slim queue panel on right, bottom now-playing controls. Compact mini-player below main window. No giant hero art. Small square album art, fictional artwork and fictional artists.
Text verbatim: window title "Music"; sidebar "Search", "Library", "Playlists", "Settings"; main heading "Evening queue"; playlist name "After hours"; right panel heading "Up next"; tracks "Night Drive", "Slow Motion", "Blue Hour", "Quiet Streets"; fictional artist "Northline"; compact player shows "Night Drive" and "Northline". Search placeholder "Search songs, artists, playlists". Bottom player includes play/pause, previous, next, shuffle, repeat, progress bar, volume.
Constraints: realistic desktop app proportions and controls, cohesive information hierarchy, adequate contrast, calm aesthetic. Render static album art. No waveform visualizer, no performance numbers, no RAM badges, no technical implementation labels, no fake account integration claims, no YouTube logo. Both main and mini-player designs should feel implementable with a native UI toolkit.
